XP-Gliding cloud styles
=======================

Put cloud styles for XP-Gliding here, one folder each, and restart X-Plane.
They show in Plugins > XP-Gliding > Cloud style.

A style sets only how the clouds look, as a livery does for an aircraft.
Where the clouds are, how big, how high and how long they live stay the
plugin's, so they still tell you about the thermals under them.

A style is a folder holding cumulus.obj, with the particle system and the
texture it names, and an optional style.txt with its name, author and
license. The simplest is a copy of xp_gliding/assets/clouds/standard with a
repainted cumulus.png.

Updating the plugin replaces only xp_gliding and PI_xp_gliding.py. This
folder and the styles in it are kept.

How to make a style:
https://github.com/jlgabriel/xp-gliding/blob/main/docs/cloud-styles.md
