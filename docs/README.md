# xp-gliding documentation

xp-gliding is in development and has not been released. This documentation is growing with it, and describes what is true today.

## Findings

What was measured about X-Plane 12 along the way, written for plugin authors and anyone curious about how it handles soaring. Each finding gives its method and limits, so the results can be checked or repeated.

- [What X-Plane 12 models natively for soaring](findings/native-soaring.md): ridge lift, thermals and wave, measured in flight.

## Still to come

- **How it works:** the thermal model, how lift is applied, the clouds and the wind. To be written once the model settles.
- **Pilot guide:** installing the plugin, a first flight, reading the sky, the menu and the HUD. To be written with the first release.
